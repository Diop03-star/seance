# Séance Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Une page web locale où l'on invoque l'esprit de COBOL, FORTRAN, BASIC ou PASCAL (Gemma 4 e2b via Ollama), qui converse, « possède » du code et laisse une pierre tombale exportable en PNG.

**Architecture:** Un serveur Node.js sans dépendance (`server.js`) sert `public/` et expose une petite API JSON qui relaie Ollama (`http://localhost:11434`) en streaming NDJSON. La logique testable (esprits, prompts, épitaphe, limites) vit dans `lib/` en modules ES ; le front est du HTML/CSS/JS vanilla.

**Tech Stack:** Node.js 22 (ESM, `node:test`, `fetch` natif), Ollama 0.40.6, `gemma4:e2b`, HTML/CSS/JS sans framework, Canvas 2D.

**Spec:** `docs/superpowers/specs/2026-10-27-seance-design.md`

## Global Constraints

- Modèle : `gemma4:e2b` ; URL Ollama par défaut `http://localhost:11434`, surchargeable par `OLLAMA_URL`.
- Zéro dépendance npm ; aucune ressource chargée depuis internet (pas de CDN, pas de Google Fonts) — polices système monospace / serif.
- Lancement : `node server.js` (port 3666, surchargeable par `PORT`) ou double-clic sur `seance.bat`.
- Bilingue FR/EN avec bouton ; langue par défaut `fr` ; choix mémorisé dans `localStorage` (try/catch).
- Esprits : `cobol` (1959, MCMLIX), `fortran` (1957, MCMLVII), `basic` (1964, MCMLXIV), `pascal` (1970, MCMLXX).
- Possession : code source ≤ 40 lignes et ≤ 4000 caractères, sinon refus avec message dans la langue.
- Épitaphe ≤ 60 caractères, dernière phrase ≤ 80 caractères ; JSON via `format: "json"` d'Ollama ; 1 nouvelle tentative puis repli manuscrit par esprit.
- Séance : réponses courtes (`num_predict` 220 en conversation, 600 en possession), `keep_alive: "30m"`.
- Style A « terminal hanté » (vert `#39ff6a` sur noir, halo, scanlines, glitchs) ; tombe réaliste selon `.superpowers/brainstorm/665-1793090834/content/pierre-tombale-v3.html` (vraies bougies CSS animées, jamais d'emoji bougie).
- Chaque réponse mesure sa durée (ms) et l'affiche discrètement (pour l'article).

## Review Focus

- Ollama éteint ou modèle absent → l'esprit « ne répond pas » avec un message clair (FR/EN) indiquant `ollama serve` / `ollama pull gemma4:e2b`, pas de page cassée. (Test : Task 2, `chat renvoie 503 si Ollama injoignable`.)
- Gemma sort hors personnage ou en anglais alors que FR est choisi → le prompt système impose la langue et le personnage ; vérifié à la main en Task 6.
- Réponse d'épitaphe en JSON invalide ou trop longue → repli / troncature sans casser la tombe. (Tests : Task 1.)
- Code collé vide, énorme, ou contenant du HTML/`<script>` → refus ou affichage échappé (jamais `innerHTML` sur du texte du modèle ou de l'utilisateur). (Test : Task 1 `checkCode` ; Task 4 utilise `textContent`.)
- Changement de langue en pleine séance → l'interface bascule, la séance continue, les réponses suivantes sont dans la nouvelle langue. (Vérif manuelle Task 6.)

```js
test('4 esprits avec données bilingues', () => {
  assert.deepEqual(Object.keys(SPIRITS).sort(), ['basic','cobol','fortran','pascal']);
  for (const s of Object.values(SPIRITS)) for (const l of ['fr','en']) {

    assert.ok(s.fallbackEpitaph[l].epitaph.length <= 60 && s.fallbackEpitaph[l].last_words.length <= 80);
  }

test('le prompt système impose la langue', () => {
  const m = buildMessages({spiritId:'cobol', lang:'fr', mode:'talk', history:[], input:'Bonjour'});
  assert.equal(m[0].role, 'system'); assert.match(m[0].content, /français/i);
  assert.deepEqual(m.at(-1), {role:'user', content:'Bonjour'});
  assert.match(buildMessages({spiritId:'cobol', lang:'en', mode:'talk', history:[], input:'hi'})[0].content, /English/);
});
test('historique tronqué à 12 messages', () => {
  const history = Array.from({length:30}, (_, i) => ({role: i%2?'assistant':'user', content:String(i)}));
  assert.equal(buildMessages({spiritId:'basic', lang:'en', mode:'talk', history, input:'x'}).length, 1 + 12 + 1);
});
test('mode possess demande un bloc de code dans la langue de l\'esprit', () => {
  assert.match(buildMessages({spiritId:'pascal', lang:'fr', mode:'possess', history:[], input:'console.log(1)'})[0].content, /```pascal/i);
});
test('parseEpitaph : JSON valide, invalide, trop long', () => {
  assert.deepEqual(parseEpitaph('{"epitaph":"Ci-gît","last_words":"Adieu"}','cobol','fr'), {epitaph:'Ci-gît', last_words:'Adieu', fallback:false});
  assert.equal(parseEpitaph('pas du json','cobol','fr').fallback, true);
  assert.equal(parseEpitaph('{"epitaph":""}','cobol','fr').fallback, true);
  assert.ok(parseEpitaph(JSON.stringify({epitaph:'x'.repeat(200), last_words:'y'.repeat(200)}),'cobol','en').epitaph.length <= 60);
});
test('checkCode', () => {
  assert.deepEqual(checkCode('  '), {ok:false, reason:'empty'});
  assert.deepEqual(checkCode('a\n'.repeat(41)), {ok:false, reason:'too_long'});
  assert.deepEqual(checkCode('x'.repeat(4001)), {ok:false, reason:'too_long'});
  assert.deepEqual(checkCode('print(1)'), {ok:true});
});

### Task 2: Serveur et relais Ollama

**Files:**
- Create: `server.js`, `lib/ollama.js`, `seance.bat` (`@echo off` / `cd /d "%~dp0"` / `start "" http://localhost:3666` / `node server.js`)
- Test: `test/server.test.js`

**Interfaces:**
- Consumes: Task 1 (`buildMessages`, `parseEpitaph`, `checkCode`, `SPIRITS`, `isLang`, `isSpirit`).
- Produces (HTTP) :
  - `GET /api/spirits` → `[{id,name,born,roman,ascii,closing,greeting:{fr,en}}]`.
  - `POST /api/chat` body `{spiritId, lang, mode:"talk"|"possess", history, input}` → `200 application/x-ndjson`, lignes `{"t":"<fragment>"}` puis `{"done":true,"ms":<int>}` ; `400 {"error":"bad_request"|"empty"|"too_long"}` ; `503 {"error":"ollama_down"}`.
  - `POST /api/epitaph` body `{spiritId, lang, history}` → `200 {epitaph, last_words, fallback, ms}` (jamais d'erreur : repli si Ollama tombe).
  - `GET /api/health` → `{ollama:boolean, model:boolean}`.
  - `createServer({ollamaUrl}) -> http.Server` exporté pour les tests ; `server.js` le lance si exécuté directement et envoie au démarrage un `POST /api/generate {model, keep_alive:"30m"}` de préchauffage (erreurs ignorées).
  - `lib/ollama.js` : `streamChat({url, messages, numPredict, signal}) -> AsyncIterable<string>`, `chatJson({url, messages}) -> string`.
